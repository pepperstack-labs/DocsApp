MDX is Markdown with a few extras. Everything you expect from Markdown works:

- **Bold** and _italic_ text
- [Links](https://mdxjs.com)
- Lists, quotes and headings

> Keep posts short and focused.

## Code blocks

```ts
export function greet(name: string) {
  return `Hello, ${name}!`;
}
```

You can also write inline HTML-like JSX, such as <mark>highlighted text</mark>.
