Welcome to the blog! Every page here is plain HTML generated when the site is
built, so there is no server, database or API to run.

## How it works

Each post is an `.mdx` file in `content/posts`. The file name becomes the URL,
and the frontmatter at the top supplies the title, date and description.

That's all there is to it.
